# 찍혔나

> 현재 속도와 전방 단속 카메라를 확인하고, 주행 기록을 기기에 남기는 Android 앱

`찍혔나`는 기기의 위치·속도 정보와 공공데이터포털의 무인교통단속카메라 데이터를 활용해 운전 중 필요한 정보를 보여줍니다. 주행과 카메라 통과 기록은 로컬 데이터베이스에 저장됩니다.

## 주요 기능

- GPS 기반 현재 속도 표시
- 이동 방향을 고려한 전방 단속 카메라 탐색
- 카메라까지의 거리, 제한 속도, 도로 정보 안내
- 수동 주행 측정과 백그라운드 자동 주행 감지
- 주행 및 카메라 통과 기록, 안전 통과율과 주의 기록 요약
- 주 운전 지역별 카메라 데이터 다운로드 및 로컬 캐싱
- 필수 약관 동의와 초기 운전 지역 설정 온보딩

## 기술 스택

- Kotlin, Java 11
- Jetpack Compose, Material 3
- AndroidX Lifecycle, ViewModel, Navigation Compose
- Android Location API, Foreground Service
- SQLite (`SQLiteOpenHelper`)
- 공공데이터포털 전국무인교통단속카메라 표준데이터 API
- Google Mobile Ads SDK

## 프로젝트 구조

```text
app/src/main/java/com/joon/chalkak/
├── data/           # 카메라 API·DB, 주행 DB, 위치 추적, 설정
├── domain/         # 위치·속도 판정, 전방 탐색, 주행 감지 규칙
├── model/          # UI에서 사용하는 주행 모델
├── presentation/   # 홈, 기록, 상세, 설정, 온보딩 Compose UI
└── ui/theme/       # 앱 테마
```

## 필요 권한

| 권한 | 용도 |
| --- | --- |
| 정밀/대략한 위치 | 현재 속도와 주변 카메라 계산 |
| 백그라운드 위치 | 자동 주행 감지 |
| 알림 | 백그라운드 주행 감지 상태 표시 |
| 인터넷 | 카메라 공공데이터 다운로드 |

위치 권한 없이는 속도 측정과 자동 주행 감지 기능을 사용할 수 없습니다. Android 13 이상에서 자동 주행 감지를 사용하려면 알림 권한도 필요합니다.

## 데이터와 주의사항

- 선택한 주 운전 지역의 카메라 데이터는 기기에 캐시됩니다.
- 주행·카메라 통과 기록은 기기의 SQLite DB에 저장되며, 설정에서 모두 삭제할 수 있습니다.
- 수동 주행은 5분 이상인 경우에만 기록됩니다.
- GPS 오차, 데이터 갱신 지연, 도로 환경에 따라 표시가 실제와 다를 수 있습니다.
- 본 앱의 속도 및 단속 위험 표시는 참고용이며, 실제 단속 여부를 보장하지 않습니다. 항상 현장의 교통법규와 표지를 우선하세요.
